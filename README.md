# 프로젝트 율도 (Project Yuldo)

조선 퓨전 판타지 루터 슈터 프로젝트.

## 현재 단계
- 기획 기반 구축
- 개발(UE5 구현)은 기획 확정 이후 진행

## 문서 운영 원칙
- GitHub를 프로젝트의 공식 문서 저장소(Source of Truth)로 사용한다.
- 기존 AI 생성 자료는 자동으로 캐논으로 인정하지 않는다.
- 설정 상태는 `[CONFIRMED]`, `[PROPOSED]`, `[REVIEW]`로 구분한다.
- 사용자 승인 없이 `[PROPOSED]` 또는 `[REVIEW]`를 `[CONFIRMED]`로 승격하지 않는다.
- 큰 뼈대 → 검수 → 확정 → 세부화 순서로 기획한다.
- 중요한 설정은 한 곳에서 정의하고 다른 문서에서는 참조한다.

## 역할 세션
00 총괄 / 01 세계관 / 02 스토리 / 03 퀘스트 / 04 플레이어·전투 / 05 무기·성장 / 06 의병·동료 / 07 월드 / 08 NPC·세력 / 09 검수 / 10 콘텐츠 / 99 인수인계

## 콘텐츠 문서군
`10_CONTENT`는 스토리 서사에 직접 포함되지 않는 게임 콘텐츠를 별도로 모아 관리한다. 개별 시스템의 원천 규칙은 기존 담당 문서가 관리하고, 10 콘텐츠에서는 실제 게임 콘텐츠의 종류·구성·목록과 시스템 간 연결을 관리한다.

현재 저장소는 문서 체계의 뼈대를 먼저 구축하고, 기존 종합 기획 자료는 이후 검수하여 단계적으로 이관한다.
