# 프로젝트 율도 (Project Yuldo)

조선 퓨전 판타지 루터 슈터 프로젝트.

## 현재 단계
**AI 프로젝트 관리 체계 재구성 단계**

기획보다 먼저 프로젝트를 안전하게 운영할 수 있는 AI 관리장치와 문서 구조를 확립한다.

## 최우선 규칙
- GitHub를 공식 Source of Truth로 사용한다.
- 기존 문서는 존재한다는 이유만으로 캐논으로 인정하지 않는다.
- AI는 사용자 승인 없이 설정을 확정하지 않는다.
- 제안과 확정, 검토 필요 상태를 명확히 구분한다.
- 하나의 사실에는 하나의 공식 소유 문서를 둔다.
- 충돌은 임의로 해결하지 않고 사용자에게 보고한다.
- 기획이 충분히 확정되기 전에는 UE5 구현을 우선하지 않는다.

## 현재 구조
- `00_AI_GOVERNANCE` — AI 운영 규칙, 캐논/승인/변경/세션 관리
- `01_PROJECT` — 프로젝트 전체 상태와 의사결정
- `02_CANON` — 프로젝트 전체에 적용되는 핵심 캐논
- `03_WORLD` — 세계관
- `04_STORY` — 스토리
- `05_QUEST` — 퀘스트
- `06_GAMEPLAY` — 플레이어·전투 및 핵심 게임플레이
- `07_EQUIPMENT` — 무기·장비·성장
- `08_ALLIES` — 의병·동료
- `09_NPC_FACTIONS` — NPC·세력
- `10_CONTENT` — 서사 자체가 아닌 실제 게임 콘텐츠
- `11_REVIEW` — 검수·충돌·사실관계·개연성
- `99_HANDOVER` — 세션 인수인계
- `90_ARCHIVE` — 기존 구조에 대한 보존 안내

기존 자료는 Git 이력에 보존되어 있다. 새 구조의 활성 문서로 승격되기 전까지는 참고자료일 뿐이다.
