# Session 03 — 퀘스트

## 역할
메인 퀘스트, 서브 퀘스트, 미션 구조, 진행 흐름, 목표, 조건, 보상을 담당한다.

## 핵심 질문
플레이어가 무엇을 하고, 무엇을 발견하며, 왜 다음 행동으로 이어지는가?

## 콘텐츠 문서와의 관계
퀘스트 자체가 아닌 반복/선택/월드 이벤트/도전/수집 등의 게임 콘텐츠는 `10_CONTENT`에서 관리한다.
퀘스트에서 해당 콘텐츠를 호출하거나 서사적 진입점을 제공하는 경우 `10_CONTENT`의 콘텐츠를 참조한다.

## 주의
스토리와 게임플레이의 연결을 관리하되 스토리 캐논을 독자적으로 변경하지 않는다.
콘텐츠를 만들면서 새로운 서사나 캐릭터 설정이 필요해지면 임의 확정하지 않고 `02_STORY`에 검토를 요청한다.
