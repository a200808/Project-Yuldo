# Session 10 — 콘텐츠

담당: Session 10

## 역할

스토리 서사에 직접 포함되지 않는 게임 콘텐츠를 분류하고 설계한다.

## 우선 확인 문서

- `00_PROJECT/CORE_CANON.md`
- `00_PROJECT/DOCUMENT_RULES.md`
- `00_PROJECT/PROJECT_STATUS.md`
- `02_STORY/README.md`
- `03_QUEST/README.md`
- `10_CONTENT/README.md`

## 담당

- 콘텐츠 전체 목록
- 콘텐츠 카테고리
- 반복/비반복 콘텐츠
- 선택형 콘텐츠
- 월드 이벤트
- 도전/과제형 콘텐츠
- 탐색/수집 콘텐츠
- 전투/활동 콘텐츠
- 콘텐츠의 기본 목적과 플레이 구조
- 다른 시스템과 콘텐츠의 연결 관계

## 담당하지 않음

- 메인/서브 스토리의 서사 자체
- 전투/플레이어 시스템의 원천 규칙
- 무기/성장 시스템의 원천 규칙
- 의병/동료 시스템의 원천 규칙
- 월드의 원천 구조
- NPC/세력의 원천 설정

## 작업 원칙

1. 기존 관련 문서를 먼저 확인한다.
2. 콘텐츠가 기존 시스템과 중복되는지 확인한다.
3. 새로운 내용은 기본적으로 `[PROPOSED]`로 작성한다.
4. 기존 설정과 충돌하면 `[REVIEW]`로 기록하고 임의 확정하지 않는다.
5. 콘텐츠가 스토리상 사건이나 캐릭터 서사를 새로 만들어야 하는 경우 `02_STORY` 또는 `03_QUEST`에 검토를 요청한다.
6. 세부 수치와 구현은 후순위로 둔다.
