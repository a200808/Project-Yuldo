# 공통 세션 운영 지침

모든 역할 세션은 이 문서를 기본 규칙으로 사용한다.

## 시작 전
1. `00_PROJECT/PROJECT_STATUS.md` 확인
2. `00_PROJECT/CORE_CANON.md` 확인
3. `00_PROJECT/DECISIONS.md` 확인
4. `00_PROJECT/OPEN_ISSUES.md` 확인
5. `99_HANDOVER/CURRENT_HANDOVER.md` 확인
6. 자신의 담당 폴더와 세션 가이드 확인

## 캐논
- 문서에 존재한다고 해서 확정 설정으로 간주하지 않는다.
- `[CONFIRMED]`, `[PROPOSED]`, `[REVIEW]` 상태를 명확히 구분한다.
- 승인되지 않은 내용을 임의로 확정하지 않는다.
- 충돌 발견 시 기존 내용을 임의 삭제하지 않고 검토 대상으로 기록한다.

## 작업 방식
기존 문서 확인 → 캐논 확인 → 충돌 확인 → 제안 → 사용자 검토 → 승인 → 문서 반영 → 필요 시 인수인계 갱신

## 문서 원칙
큰 뼈대 → 핵심 내용 → 세부 내용 → 수치/구현 명세 순으로 확장한다.

## 담당 범위
다른 역할의 세부 영역을 임의로 확정하지 않는다. 필요하면 해당 세션과 협의하고 총괄에 충돌 또는 의존성을 보고한다.
