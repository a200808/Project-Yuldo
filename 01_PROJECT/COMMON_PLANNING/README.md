# 공통 기획 질문지 세트

Status: [CONFIRMED]
Approval: 사용자 승인 — 2026-10-29
Owner: YULDO-AI-GENERAL (coordination); relevant specialist AIs (domain responses); YULDO-AI-REVIEW (independent review)

## 목적
파트별 AI와 세션이 공통 전제에서 출발하고, 서로 다른 시스템이 결합해도 같은 게임을 설계하도록 공통 질문과 검증 절차를 제공한다.

## Canon 범위
- 이 질문지 세트의 구성, 질문 범주, 권장 진행 순서는 Confirmed다.
- 각 질문의 답변은 별도 판단이다. 질문지 세트의 Confirmed 상태가 모든 답변이나 예시 시나리오를 Confirmed로 만들지 않는다.
- 각 질문은 [OPEN], [PROPOSED], [CONFIRMED], [REVIEW], [N/A] 상태로 관리한다. 사용자가 승인한 답변만 [CONFIRMED]로 표시한다.
- 기존 Confirmed 내용이 답을 제공하면 재결정하지 않고 출처를 연결한다.
- 새로운 세계관·스토리·시스템 설정은 승인 전까지 Proposed로 남긴다.
- 질문에 답하기 위해 필요하지 않은 세부 수치·개별 장비·개별 퀘스트·구현 상세는 해당 전문 파트로 이관한다.

## 질문 진행 형식
모든 질문에는 아래 항목을 표시한다.
- 순서: 예) 질문지 1 / A / 질문 1
- 질문지 제목
- 절대 주소: https://github.com/... 전체 주소
- 질문 원문
- 질문 상태
- 이 질문이 선행 조건인 이유 또는 영향 범위(필요한 경우)
- 사용자 답변을 받은 뒤: 답변 요약, 상태, 관련 Confirmed/Proposed 출처, 영향받는 질문

한 번에 하나의 질문만 제시한다. 사용자가 답하면 그 답변을 정리하고, 다음 순서의 미결 질문으로 진행한다. 답변이 모호하거나 기존 Confirmed와 충돌하면 추측으로 채우지 말고 추가 확인을 요청한다.
