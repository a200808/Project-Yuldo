# 10 콘텐츠

담당: Session 10

## 목적

스토리 서사에 직접 포함되지 않는 게임 콘텐츠를 목록화하고 설계한다.

이 폴더는 개별 시스템의 규칙이나 스토리 캐논을 대체하지 않는다. 게임에 실제로 어떤 콘텐츠가 존재하는지, 콘텐츠의 목적과 구성, 플레이 방식, 연결되는 시스템을 관리하는 콘텐츠 레이어다.

## 주요 대상

- 반복/비반복 콘텐츠
- 선택형 콘텐츠
- 월드 이벤트
- 도전/과제형 콘텐츠
- 탐색/수집 콘텐츠
- 전투/활동 콘텐츠
- 콘텐츠 보상 구조의 개요
- 콘텐츠 카테고리 및 전체 목록

## 문서 경계

- 스토리와 메인/서브 퀘스트의 서사 자체는 `02_STORY`, `03_QUEST`가 담당한다.
- 플레이어/전투 규칙은 `04_PLAYER_COMBAT`가 담당한다.
- 무기/성장 규칙은 `05_WEAPONS_GROWTH`가 담당한다.
- 의병/동료 규칙은 `06_ALLIES` 또는 `06_SQUAD`가 담당한다.
- 월드 구조는 `07_WORLD`, `07_WORLD_DESIGN`이 담당한다.
- NPC/세력 설정은 `08_NPC_FACTIONS`가 담당한다.
- 10 콘텐츠는 위 시스템들을 조합하여 실제 플레이 콘텐츠의 종류와 구성을 관리하고 필요한 경우 해당 문서를 참조한다.

## 상태

[CONFIRMED] 콘텐츠 문서군을 별도 관리한다.

세부 콘텐츠는 사용자 검토 전까지 `[PROPOSED]` 또는 `[REVIEW]` 상태로 관리한다.
