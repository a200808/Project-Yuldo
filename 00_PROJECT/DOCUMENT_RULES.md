# Document Rules

## 1. 작성 순서
큰 뼈대 → 핵심 내용 → 세부 내용 → 수치/구현 명세

## 2. 캐논 상태
- `[CONFIRMED]` 공식 확정
- `[PROPOSED]` 제안
- `[REVIEW]` 검토 필요

## 3. 중복 캐논 금지
중요한 설정은 한 곳에서 공식 정의하고 다른 문서에서는 참조한다.

## 4. 기존 문서 검토
기존 자료가 존재한다는 이유만으로 사실 또는 확정 설정으로 취급하지 않는다.

## 5. 변경 원칙
기존 설정과 충돌하면 임의로 덮어쓰지 않고 충돌 내용을 기록한다.

## 6. 승인 절차
1. 기존 문서 확인
2. 캐논 확인
3. 충돌 확인
4. 초안/제안 작성
5. 사용자 검토
6. 사용자 승인
7. `[CONFIRMED]` 반영
8. GitHub 저장
9. 필요 시 인수인계 갱신

## 7. 개발 문서화
기획이 충분히 확정되기 전에는 UE5 코드/블루프린트 구현을 우선하지 않는다.
