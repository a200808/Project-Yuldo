# Session Prompts

각 AI 역할을 별도 세션으로 실행할 때 사용하는 짧은 시작 프롬프트 모음이다.

## 사용법

해당 역할의 세션 프롬프트를 새 세션에 넣는다. 세션은 프롬프트에 지정된 순서대로 공식 GitHub의 역할 Prompt, 운영 규칙, Confirmed, Proposed 및 필요한 참고 문서를 읽은 뒤 작업을 시작한다.

## 역할별 세션

- ROUTER → `ROUTER_SESSION.md`
- GENERAL → `GENERAL_SESSION.md`
- WORLD → `WORLD_SESSION.md`
- STORY → `STORY_SESSION.md`
- QUEST → `QUEST_SESSION.md`
- GAMEPLAY → `GAMEPLAY_SESSION.md`
- EQUIPMENT → `EQUIPMENT_SESSION.md`
- ALLIES → `ALLIES_SESSION.md`
- NPC_FACTIONS → `NPC_FACTIONS_SESSION.md`
- CONTENT → `CONTENT_SESSION.md`
- REVIEW → `REVIEW_SESSION.md`

## 원칙

세션 프롬프트는 역할 Prompt를 대체하지 않는다. 역할 Prompt를 읽게 만드는 부트스트랩이며, 공식 역할 Prompt와 공통 AI 운영 규칙이 우선한다.

세션 프롬프트 자체의 변경이 필요한 경우에도 Confirmed/Proposed 규칙과 변경 통제를 따른다.
