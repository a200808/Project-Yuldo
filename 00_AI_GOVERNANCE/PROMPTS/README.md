# 세션 부트스트랩 프롬프트

각 세션의 AI에게 이 디렉터리의 해당 프롬프트 파일 이름만 전달하면 된다.

예: `00_GENERAL.md` → 총괄 세션

## 사용 규칙
1. 프롬프트를 읽는다.
2. 프롬프트가 지정한 AI Governance 문서를 먼저 읽는다.
3. 자신의 담당 영역과 다른 영역의 소유권을 침범하지 않는다.
4. 문서에 없는 내용은 기존 설정으로 간주하지 않는다.
5. 제안은 `[PROPOSED]`, 충돌/검토 사항은 `[REVIEW]`로 취급한다.
6. 사용자 승인 없이 `[CONFIRMED]`를 만들지 않는다.
7. 작업 시작 전에 관련 활성 문서를 확인한다.

프롬프트는 작업 지침이며 프로젝트 캐논 자체가 아니다. 캐논은 `02_CANON`과 Source of Truth 규칙에 따른다.
