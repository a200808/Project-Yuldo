1. 기존 관련 문서 확인
2. Source of Truth 확인
3. 현재 캐논 상태 확인
4. 충돌/영향 범위 확인
5. 제안 작성
6. 사용자 검토
7. 사용자 승인

9. 변경 사유 기록
10. 필요 시 인수인계 갱신

핵심 캐논, 스토리 구조, 시스템의 근본 규칙, 문서 소유권 변경은 변경 이유를 기록한다.
