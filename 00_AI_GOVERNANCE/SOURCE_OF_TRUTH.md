# Source of Truth 규칙

Status: [CONFIRMED]

## 원칙
하나의 설정/규칙/사실에는 하나의 공식 소유 문서를 둔다.

## 소유 영역
- 프로젝트 전체 원칙/방향 → `01_PROJECT`
- 프로젝트 전체 핵심 캐논 → `02_CANON`
- 세계관 규칙 → `03_WORLD`
- 스토리 → `04_STORY`
- 퀘스트 → `05_QUEST`
- 플레이어/전투/핵심 게임플레이 → `06_GAMEPLAY`
- 무기/장비/성장 → `07_EQUIPMENT`
- 의병/동료 → `08_ALLIES`
- NPC/세력 → `09_NPC_FACTIONS`
- 비서사 게임 콘텐츠 → `10_CONTENT`
- 검수 결과/충돌 기록 → `11_REVIEW`

## 참조 규칙
다른 문서에서 이미 정의된 내용을 다시 캐논으로 복제하지 않는다.
필요하면 원본 문서를 참조한다.

## Archive 규칙
`90_ARCHIVE`는 참고자료 보관소다.
Archive 문서의 내용은 활성 캐논이 아니다.
