# 캐논 상태 규칙

Status: [CONFIRMED]

## 상태
- `[CONFIRMED]` — 사용자가 승인했거나 공식적으로 확정된 내용
- `[PROPOSED]` — AI/팀이 제안했지만 승인되지 않은 내용
- `[REVIEW]` — 충돌, 역사적 사실, 개연성, 시스템 모순 등의 검토가 필요한 내용
- `[DEPRECATED]` — 과거에는 사용했으나 현재 기준으로 폐기된 내용. 기록 보존을 위해 남김

## 승격 규칙
`PROPOSED → CONFIRMED`는 사용자 승인 없이 불가능하다.
`REVIEW → CONFIRMED` 역시 사용자 승인 없이 불가능하다.

## 문서 상태와 개별 항목 상태
문서 전체가 확정 문서라는 이유만으로 내부의 모든 세부 내용이 자동 확정되는 것은 아니다.
중요한 미확정 항목은 개별 상태를 표시한다.
