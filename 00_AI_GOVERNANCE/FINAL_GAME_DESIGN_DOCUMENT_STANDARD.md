# 최종 통합 게임 기획서 기준

Status: [CONFIRMED]

최종 기획서는 요약본이 아니라 개발자/기획자/아티스트/QA 등이 읽었을 때 가능한 한 동일한 게임을 상상하고 같은 결과를 예상할 수 있게 하는 상세 설계 기준이다.

플레이어 경험(보고, 듣고, 선택하고, 조작하고, 피드백 받고, 결과를 경험하는 과정), 시스템 로직(목적, 입력, 조건, 상태, 처리, 결과, 예외, 우선순위, 연결), 콘텐츠(스토리, 캐릭터, 지역, 퀘스트, 적, 무기, 장비, 동료, 이벤트), 세계관 논리를 모두 다룬다.

분량은 인위적으로 제한하지 않는다. 장황함이 목적은 아니며 필요한 만큼 상세하게 정의한다.

핵심 시스템은 입력 → 조건 → 처리 → 결과 → 상태 변화 → 예외 수준으로 명확히 한다. Player View와 System Logic을 구분한다. 정상 흐름뿐 아니라 실패, 잘못된 입력, 조건 미충족, NPC 부재, 월드 상태 변화, 이동 차단, 시스템 우선순위 충돌 등의 예외도 정의한다.

핵심 용어는 하나의 공식 정의를 가진다. 필요한 경우 공식 명칭/별칭/플레이어 표시명/NPC 명칭/내부 명칭을 구분한다.

최종 통합은 개별 문서 → 영역 정리 → 영역 연결 → 충돌 검수 → 누락 검수 → 용어 통일 → 로직 정리 → 플레이어 경험 검수 → 통합 기획서 순으로 진행한다.

통합 과정에서 새 설정을 임의로 만들지 않는다. 필요하면 Proposed로 분리하고 승인 후 반영한다.

완성 기준은 재현 가능성, 일관성, 완결성, 추적 가능성이다. 다른 사람이 문서를 읽고 같은 게임을 설계할 수 있어야 한다.
