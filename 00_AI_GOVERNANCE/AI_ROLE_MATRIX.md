# AI 역할 및 접근 권한 매트릭스

Status: [CONFIRMED]

## 목적
각 AI/세션의 담당 범위와 문서 접근·수정 원칙을 명확히 하여, 서로 다른 세션이 다른 영역의 캐논을 임의로 변경하지 않도록 한다.

> 주의: 이 문서는 현재 ChatGPT/GitHub 연결에서 사용하는 **논리적 권한 규칙**이다. GitHub 자체의 폴더별 쓰기 권한을 기술적으로 강제하는 ACL은 아니다.

## 핵심 원칙
1. 각 AI는 자신의 담당 영역을 우선적으로 책임진다.
2. 다른 영역은 원칙적으로 읽기/참조만 한다.
3. 다른 영역의 설정을 수정해야 할 필요가 있으면 해당 담당 AI 또는 GENERAL/ROUTER로 이관한다.
4. `02_CANON`의 핵심 캐논은 담당 AI가 임의로 확정하지 않는다.
5. `[PROPOSED]`는 사용자 승인 전까지 공식 캐논이 아니다.
6. 사용자 승인 전에는 `[CONFIRMED]`로 승격하지 않는다.
7. `11_REVIEW`의 검수 결과는 판단 자료이며, 그 자체로 캐논을 변경하지 않는다.

## 공통 접근 규칙

| 영역 | 기본 권한 | 비고 |
|---|---|---|
| `00_AI_GOVERNANCE` | 읽기 | AI 운영 규칙 확인용. 변경은 GENERAL/사용자 승인 필요 |
| `01_PROJECT` | 읽기 | 프로젝트 방향/상태 확인 |
| `02_CANON` | 읽기 | Source of Truth. 임의 수정 금지 |
| 담당 영역 | 읽기/제안 작성 | 담당 AI의 주 작업 영역 |
| 타 영역 | 읽기 | 영향 검토 및 참조 목적 |
| `11_REVIEW` | 읽기/검수 결과 작성 | REVIEW AI 중심 |
| `90_ARCHIVE` | 읽기 | 활성 캐논 아님 |
| `99_HANDOVER` | 읽기/인수인계 작성 | 장기 운영 필요 시 갱신 |

## 역할별 책임

### YULDO-AI-ROUTER
- 목적: 사용자 아이디어를 분류하고 적절한 담당 AI로 연결
- 주 작업: 요청 해석, 영역 분류, 다중 영역 분해, 작업 순서 제안
- 캐논 확정: 금지
- 공식 캐논 수정: 금지

### YULDO-AI-GENERAL
- 목적: 프로젝트 전체 관리
- 주 작업: 우선순위, 프로젝트 상태, 세션 분업, 문서 구조, 교차 영역 조정
- 캐논 확정: 사용자 승인 없이 금지
- 영역 문서 직접 수정: 원칙적으로 담당 AI에 위임

- 캐논 확정: 금지
- 검수 결과를 근거로 수정안을 제시할 수 있으나, 최종 결정은 사용자에게 있다.

## 승인 게이트

다음 순서를 기본 표준으로 사용한다.

`아이디어 → ROUTER → 담당 AI → [PROPOSED] → REVIEW → 사용자 보고 → 사용자 승인 → [CONFIRMED] → Source of Truth 반영`

사용자 승인 전에는 어떤 AI도 제안 내용을 공식 캐논으로 취급하지 않는다.

## 외부/교차 영역 변경
교차 영역 변경이 필요한 경우:
1. 영향 받는 담당 AI를 식별한다.
2. 각 담당 AI가 자신의 영역에 대한 검토를 수행한다.
3. REVIEW AI가 충돌 및 리스크를 검수한다.
4. 사용자 승인 후 공식 문서에 반영한다.

## 기술적 한계
현재 연결된 GitHub 권한은 저장소/계정 수준으로 동작하므로 이 매트릭스만으로 폴더별 기술적 쓰기 차단을 보장할 수 없다.

따라서 **현재 단계에서는 운영 규칙으로 적용**하고, 추후 자동화/API를 구축할 때 별도 GitHub 계정·앱·토큰 또는 저장소 분리를 이용해 실제 권한으로 승격한다.

## 변경 이유
기존 단일 저장소 구조에서 AI별 담당 범위를 명확히 하여 교차 수정과 캐논 오염을 방지하기 위해 추가했다.
