# ACT 0 / 프롤로그 퀘스트 구조 제안

상태: [PROPOSED]
담당: Session 03 — 퀘스트
작성일: 2026-08-23

## 목적

현재 [CONFIRMED] 스토리에서 ACT 0에 해당하는 사건을 실제 메인 퀘스트로 직접 구성할 경우, 플레이어의 성공/실패와 스토리상 고정된 결과가 충돌할 가능성이 있다.

따라서 ACT 0을 일반 메인 퀘스트 구간이 아니라 **프롤로그 시퀀스**로 처리하고, 실제 플레이어의 성취를 중심으로 하는 메인 퀘스트는 ACT 1부터 시작하는 구조를 제안한다.

## 제안 구조

```text
ACT 0 — 프롤로그
└─ 컷씬 / 플레이블 시네마틱 시퀀스
   ├─ 홍길동이 탐관오리를 처단하러 감
   ├─ 이상한 연발총과 조우
   ├─ 홍길동이 후퇴
   ├─ 축지 부적 탈취
   └─ 장거리 축지에 이상 발생

ACT 1
├─ Q01
├─ Q02
└─ Q03 ...
```

## 제안 이유

### 1. Q01의 문제

현재 확정된 스토리에서 홍길동은 탐관오리를 처단하려 하지만, 이상한 연발총과의 조우 이후 그 목적을 달성하지 못한다.

이를 일반 퀘스트의 성공/실패 구조로 만들 경우 플레이어가 충분히 잘 플레이했음에도 스토리상 실패하도록 강제하는 문제가 발생할 수 있다.

### 2. Q02의 문제

축지 부적을 빼앗기는 사건 역시 현재 스토리에서 중요한 고정 사건이다.

이를 플레이어가 직접 수행하는 퀘스트로 만들 경우, 플레이어의 결과와 확정 스토리의 결과를 어떻게 조화시킬지 추가 설계가 필요하다.

### 3. 퀘스트의 역할과의 충돌 방지

메인 퀘스트는 플레이어에게 목표와 성취감을 제공하고, 스토리에 맞는 행동을 유도하는 장치로 설계한다.

따라서 플레이어의 결과를 사전에 확정해야 하는 사건은 일반 퀘스트보다 컷씬 또는 플레이블 시네마틱으로 처리하는 편이 적합할 수 있다.

## 기대 효과

- 확정된 ACT 0 사건을 플레이어의 실력과 무관하게 안정적으로 전달할 수 있다.
- ACT 1부터 플레이어가 직접 달성할 수 있는 목표를 중심으로 메인 퀘스트를 설계할 수 있다.
- 퀘스트 성공/실패와 스토리상 고정 사건의 충돌을 줄일 수 있다.
- Q 번호를 실제 메인 퀘스트가 시작되는 ACT 1부터 부여하는 구조를 검토할 수 있다.

## 검토 필요 사항

- ACT 0을 실제 게임에서 완전한 컷씬으로 처리할지, 일부 구간을 플레이블 시네마틱으로 제공할지
- 실제 메인 퀘스트 번호를 ACT 1의 Q01부터 시작할지
- ACT 0의 현재 확정 스토리 사건을 별도 프롤로그 문서에서 어떻게 참조할지
